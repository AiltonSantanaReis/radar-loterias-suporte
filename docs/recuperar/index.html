Esta página procura os dados que o antigo Mega-Sena Radar guardou neste navegador e prepara arquivos para você importar no aplicativo atual.

Use o mesmo aparelho, navegador e perfil do aplicativo antigo. Não limpe os dados nem desinstale a versão antiga antes de guardar suas cópias. Dados já apagados não podem ser recuperados por esta página.

A consulta só começa quando você tocar no botão. Seus jogos não são enviados para um servidor, alterados ou apagados.

Jogos e preferências

Plano de bolão

Os arquivos são separados. A cópia dos jogos inclui o preço e as preferências de filtros salvas; o histórico local de resultados não faz parte dela. O aplicativo valida cada arquivo ao importar.

2. Importar no aplicativo atual

  1. Guarde os arquivos JSON baixados. No iPhone, se aparecer uma prévia, use o compartilhamento para salvar o arquivo em Arquivos.
  2. Abra o Mega-Sena completo. Em Meus jogos, toque em Importar jogos do arquivo e escolha a cópia dos jogos.
  3. Para o segundo arquivo, abra Bolão e toque em Importar bolão do arquivo. Essa ação substitui o plano de bolão que estiver no aplicativo atual; guarde uma cópia dele antes, se precisar.

Não encontrou os dados?

Confira se está no navegador e no perfil usados anteriormente. Navegação privada, dados removidos e armazenamento separado de um aplicativo instalado podem impedir a recuperação por esta página.

Se o aplicativo antigo ainda abrir, use Meus jogos → Baixar cópia dos jogos e Bolão → Baixar cópia do bolão nele. A versão instalada e o navegador podem ter dados diferentes.

Relatar um problema técnico. O relato é público: não anexe backups, senhas, documentos ou comprovantes.

Esta recuperação funciona apenas para dados do Mega-Sena Radar guardados no endereço ailtonsantanareis.github.io. Ela não consulta dados de outros projetos, não registra service worker e não faz transferência automática entre domínios.
